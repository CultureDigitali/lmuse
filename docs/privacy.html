lmuse — Privacy Policy

Ultimo aggiornamento: 20 ottobre 2026 · lmuse

lmuse è un'estensione Chrome che esegue task nel browser tramite un modello linguistico scelto dall'utente, con la propria chiave API (BYOK). Questa pagina descrive quali dati tratta e dove restano.

Privacy Gateway 0.9.0 (beta)

La modalità rigorosa consente all'utente di approvare ogni sito prima che il suo contenuto raggiunga il provider LLM. Email, numeri telefonici, IBAN, carte e alcuni token riconosciuti sono trasformati in pseudonimi casuali nel browser. La mappa per il ripristino vive solo nella memoria della singola esecuzione e non viene inviata al provider. La scrittura con ripristino è consentita solo nel sito d'origine, dopo approvazione. Screenshot e upload automatici sono disabilitati nelle modalità protette.

Questa protezione non equivale a anonimizzazione completa. Nomi, testi liberi, contenuti non riconosciuti e informazioni inferibili dal contesto possono comunque essere condivisi con il provider e diventare dati personali. La chiave API viene trasmessa al provider scelto per autenticazione. Nessun file binario viene inviato direttamente al modello; la beta non offre parser universali per documenti PDF, fogli di calcolo o immagini.

Nessun server nostro, nessuna telemetria

Lo sviluppatore non gestisce server, non raccoglie statistiche d'uso, non vende dati e non include tracker o pubblicità. Non esiste alcun invio di dati a infrastrutture del progetto.

Dati salvati sul dispositivo

  • Impostazioni (provider, modello, policy di approvazione, domini fidati, template).
  • Chiavi API, in un record separato per provider, in chrome.storage.local o chrome.storage.session (cancellate alla chiusura del browser in quest'ultimo caso).
  • Cronologia degli ultimi task, conteggi d'uso (run e token) e risultato dell'ultimo run (quest'ultimo solo in memoria di sessione).
  • Cache locale della lista modelli letta dal provider scelto, se usi il pulsante di aggiornamento.

A chi vengono inviati i dati

Durante un task, lmuse invia al provider LLM che hai configurato: il testo del task, il contenuto della pagina con pseudonimizzazione dei valori strutturati riconosciuti nelle modalità protette. Le informazioni residue possono ancora identificare persone. Screenshot sono consentiti solo nella modalità non protetta. Questi dati vanno esclusivamente al provider scelto, secondo la sua informativa. lmuse non li invia ad altri soggetti.

Permessi e perché servono

  • storage: impostazioni e chiavi solo locali.
  • scripting: analisi della pagina solo quando un task la richiede (iniezione on-demand).
  • tabs / activeTab: leggere e operare sul tab attivo, elencare le schede.
  • sidePanel: mostrare l'interfaccia nel pannello laterale.
  • alarms: task programmati locali.
  • nativeMessaging: solo per il bridge opencode opzionale, installato separatamente dall'utente; il bridge legge auth.json di opencode in locale e non usa la rete.
  • host su tutti i siti: l'agente deve poter operare dove l'utente lo chiede; è disponibile un elenco di domini consentiti per restringere il perimetro.

Controllo e cancellazione

“Cancella tutti i dati” nelle impostazioni elimina chiavi, impostazioni, cronologia, coda, statistiche e flag di onboarding. La disinstallazione dell'estensione rimuove i dati locali secondo le regole di Chrome.

English summary

lmuse is a Chrome extension that performs browser tasks using a language model of your choice and your own API key. The developer runs no servers, collects no telemetry and sells no data. Settings and API keys are stored locally in chrome.storage. During a task, the task text, a redacted page page content pseudonymized for recognized structured identifiers is sent to the chosen LLM provider. Free text and context can still reveal personal information; screenshots are blocked in protected modes. The optional opencode bridge runs locally, reads opencode's auth.json and makes no network requests. Use “Cancella tutti i dati” to delete everything stored locally.
